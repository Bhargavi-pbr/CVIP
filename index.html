The Smart Desk Object Detection and Monitoring System combines classical digital image processing principles with modern deep learning convolutional architectures to evaluate workspace cleanliness, ergonomics, study distractions, and liquid spill hazards.

1. System Architecture & Processing Pipeline

The system executes an 8-stage image processing and vision inference pipeline:

  1. Image Acquisition: Frame sampled from video feed or static image matrix \( I(x, y) \).
  2. Color Space Conversion: ITU-R BT.601 luminance mapping \( Y = 0.299R + 0.587G + 0.114B \).
  3. Gaussian Filtering: 2D convolution with a \( 5\times5 \) normalized kernel for noise suppression.
  4. Gradient Derivation: Sobel operators \( G_x, G_y \) compute edge magnitude and orientation angle \( \theta \).
  5. Canny Edge Detection: Non-Maximum Suppression (NMS) and double-threshold hysteresis.
  6. Otsu Global Binarization: Separates foreground clutter by maximizing inter-class variance \( \sigma_B^2 \).
  7. Neural Object Detection: Single-shot multi-box detection (COCO-SSD / MobileNetV2) computing class probabilities and bounding box coordinates.
  8. Spatial Proximity & Clutter Analytics: Evaluates Euclidean hazard distances and the Desk Clutter Index (DCI).

2. Mathematical Formulations

Desk Clutter Index (DCI):
\[ \text{DCI} = \min\left(100, \; 100 \times \left[ 0.35 \cdot \min\left(\frac{N}{8}, 1\right) + 0.40 \cdot \frac{\sum_{i=1}^N \text{Area}(B_i)}{\text{Area}_{\text{desk}}} + 0.25 \cdot E_{\text{density}} \right]\right) \]
Spill Hazard Proximity Metric:
\[ d_{\text{hazard}} = \min_{i \in \text{Liquids}, j \in \text{Tech}} \sqrt{(x_i - x_j)^2 + (y_i - y_j)^2} \] \[ \text{Condition: If } d_{\text{hazard}} < 110\text{px} \implies \text{CRITICAL HAZARD ALARM} \]
Intersection over Union (IoU):
\[ \text{IoU}(B_{\text{pred}}, B_{\text{gt}}) = \frac{\text{Area}(B_{\text{pred}} \cap B_{\text{gt}})}{\text{Area}(B_{\text{pred}} \cup B_{\text{gt}})} \]

3. Frequently Asked Viva / Examination Questions & Model Answers

Q1: Why convert the RGB image to Grayscale before running Canny edge detection?
Color information adds 3 redundant spatial channels (\(R, G, B\)). Edges correspond to high-frequency spatial discontinuities in luminance. Converting to grayscale with luminance weights (\(0.299R + 0.587G + 0.114B\)) preserves human visual perception while reducing computational complexity by 66%.
Q2: What are the 5 core stages of the Canny Edge Detection algorithm?
1. Gaussian Blur (noise suppression), 2. Sobel Gradient Magnitude and Direction Calculation, 3. Non-Maximum Suppression (edge thinning), 4. Double Thresholding (identifying strong, weak, and non-edge pixels), and 5. Edge Tracking by Hysteresis (suppressing weak edges not connected to strong ones).
Q3: How does Otsu's thresholding method determine the optimal binarization threshold?
Otsu's algorithm exhaustively iterates through all 256 grayscale levels to find the threshold \( T^* \) that maximizes between-class variance: \( \sigma_B^2(T) = w_0(T) w_1(T) [\mu_0(T) - \mu_1(T)]^2 \), which equivalently minimizes intra-class variance without requiring manual heuristic tuning.
Q4: How does the Spill Hazard detection prevent false alarms?
It specifically pairs classes categorized as liquids (cup, mug, bottle) with sensitive electronics (laptop, keyboard, mouse) and applies a minimum Euclidean distance threshold (\( d < 110\text{px} \)). Items outside the danger zone or two tech items placed next to each other do not trigger the spill warning.
Q5: Why use the HSV color space for beverage detection instead of RGB?
In RGB, color chromaticity and luminance intensity are tightly coupled. Under changing workspace lighting or shadow, RGB pixel values shift dramatically. In HSV, Hue (\(H\)) represents pure color wavelength independent of illumination Value (\(V\)) and Saturation (\(S\)), making color segmentation robust against lighting variations.
